MTN Uganda APN Settings: How to Set Up Mobile Internet

If your MTN Uganda SIM has signal but mobile internet will not load, the Access Point Name (APN) is one setting worth checking. Start with MTN’s official automatic setup where available.

For Uganda · Reviewed 23 October 2026 · Independent guide

Stay safe: Never share your mobile money PIN, password, or one-time verification code with anyone offering technical help.

What APN should MTN Uganda use?

MTN Uganda’s official internet-settings page lists internet as the APN for manual setup. It also lists an automatic setup option: dial *160*10#, receive the settings, then accept and save them as the default profile. Codes and menus can change, so consult MTN’s page if the code does not work.

If the phone already has a working MTN profile, keep it unless MTN support directs you to change it.

Check APN settings on Android

  1. Open Settings.
  2. Open Network & internet, Connections, or SIM cards & mobile networks.
  3. Select your MTN SIM if the phone has two SIM cards.
  4. Open Mobile networks or Access Point Names (APN). You can also search Settings for “APN”.
  5. Select the existing MTN profile and check whether the APN is internet.
  6. If you need a new profile, name it MTN and enter internet as the APN. Leave other fields unchanged unless MTN instructs otherwise.
  7. Save, select the profile, toggle mobile data, and test a website.

Check APN settings on iPhone

  1. Open Settings, then Mobile Service or Mobile Data.
  2. If available, open Mobile Data Network and inspect the APN field.
  3. Use the provider-approved value; leave username and password blank unless MTN says otherwise.
  4. If the APN menu is missing or locked, ask MTN to verify settings for your SIM and device. Do not install profiles from unknown websites.

Apple Support: View and edit your APN.

If mobile data still does not work

  1. Confirm mobile data is on and MTN is selected as the data SIM.
  2. Check that your bundle or data allowance is active.
  3. Turn Airplane mode on for about 10 seconds, then off.
  4. Restart the phone and test in a location with better signal.
  5. Try more than one website to see whether the issue affects every app.
  6. If a recent APN change caused the problem, use “Reset to default” if available, then try MTN’s official setup.
  7. If it still fails, contact MTN through its official website and ask them to check your line, coverage, and device settings.

Safety note

APN settings do not create a data bundle, bypass payment, or guarantee faster internet. Avoid “free internet” APNs or apps that ask you to install unknown certificates or profiles.
