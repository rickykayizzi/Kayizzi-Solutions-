Airtel Uganda APN Settings: How to Configure Mobile Internet

If your Airtel Uganda SIM shows signal but cannot open websites, check mobile data, the selected SIM, and the APN profile. Settings can vary by device, so preserve working defaults and verify details with Airtel when in doubt.

For Uganda · Reviewed 23 October 2026 · Independent guide

Stay safe: Never share your mobile money PIN, password, or one-time verification code with anyone offering technical help.

What APN is commonly listed for Airtel Uganda?

Public APN references for Airtel Uganda commonly list internet as the APN. We could not confirm a current detailed APN table on an Airtel Uganda support page while preparing this guide, so treat this as a starting point—not a guarantee for every SIM or device. Check the APN on Android

  1. Open Settings and search for APN or Access Point Names.
  2. Open SIM or mobile network settings and select your Airtel SIM.
  3. Inspect the existing Airtel profile.
  4. If Airtel support confirms a new profile is needed, add one named Airtel Internet and enter internet in the APN field.
  5. Leave other fields at their current defaults unless Airtel gives you exact values.
  6. Save and select the profile, toggle mobile data, and test a website.

Check the APN on iPhone

  1. Open Settings, then Mobile Service or Mobile Data.
  2. If Mobile Data Network is available, inspect the APN field.
  3. Only change it after verifying the correct value with Airtel. Some iPhones do not expose editable APN fields.
  4. Do not install unknown configuration profiles from links or messages.

Apple Support: View and edit your APN.

Airtel data not working? Try these checks

  1. Make sure Airtel is selected as the mobile-data SIM on dual-SIM phones.
  2. Check that mobile data is on and your bundle or allowance is available.
  3. Turn Airplane mode on for 10 seconds, then off.
  4. Restart the phone and test in another location to rule out weak coverage.
  5. Test more than one app or website.
  6. Restore the default APN if a recent change caused the issue.
  7. Contact Airtel Uganda through its verified official channels if the line still cannot connect.

Important note

An APN change will not fix exhausted bundles, poor coverage, a suspended SIM, or a temporary network outage. Never share your mobile money PIN, password, or one-time code with anyone offering technical help.
